# Reserva — 2026-11-15, depois da terceira rodada de marcações

Os candidatos que passaram em tudo na ampliação para 900 (pelo menos 400 visualizações por mês na Wikipédia em português, carreira com mais de um clube e todos os clubes no catálogo) e ainda estão fora do jogo. Eram 79; 55 entraram no lugar dos 55 que o cliente marcou para tirar na terceira rodada.

Estão na ordem da régua de agora, do mais reconhecível para o menos, com a chance que ela dá de o cliente marcar "tirar" e o nível em que ela poria cada um. A régua erra bastante nos antigos: o cliente tirou 25 dos 58 nascidos antes de 1965 que marcou, inclusive campeões do mundo como Zagallo, Gérson e Jorginho. Para os nascidos antes de 1965 desta lista, vale perguntar antes de trazer.

O Zé Roberto da reserva (Q720593, José Roberto de Oliveira, de Mirassol, Schalke e Flamengo) ficou de fora de propósito: o Zé Roberto do Bayern e do Palmeiras já está no jogo, e quem digitasse "Zé Roberto" acertaria os dois.

Para trocar alguém que o cliente mandar tirar: marque "tirar" em `scripts/amostra-nivel.json` e mova o id do Transfermarkt para `foraDaBiblioteca`, tire o jogador de `src/dados/jogadores.json` (se ele não estiver na agenda de hoje), traga o próximo da lista com o argumento da última coluna e rode o resto do caminho:

```bash
npm run trazer -- Q630133:dificil:fernando-henrique
npm run catalogo && npm run dicas && npm run regua -- --gravar && npm run agenda
```

O nível do argumento é provisório; a régua decide o de verdade.
